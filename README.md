# Car-Sales-Analysis-Excel
Project Description

This project focuses on analyzing car sales data using Microsoft Excel to gain meaningful business insights. The dataset contains 1,200 records covering sales from 2018 onwards, including car models, sales dates, dealer IDs, quantity sold, and profit.

Project Objectives

Analyze total car sales by model.

Identify top-performing dealers.

Calculate total profit generated by different car models.

Analyze monthly and yearly sales performance.

Compare dealer-wise sales and profitability.

Identify trends and patterns in car sales.

Tools & Technologies

Microsoft Excel

Pivot Tables

Data Analysis

Data Visualization

Excel Charts

Key Insights

Evaluated sales performance across different car models.

Compared dealer-wise quantity sold and profit.

Analyzed profit contributions from individual car models.

Explored yearly and monthly sales trends.

Skills Demonstrated

Data Cleaning, Data Analysis, Excel Functions, Pivot Tables, Business Intelligence, and Data Visualization.

Conclusion

This project demonstrates my ability to use Microsoft Excel for data analysis and transform raw sales data into meaningful business insights that support data-driven decision-making.
